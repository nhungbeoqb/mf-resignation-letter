The one-line resignation letter of an exponential-backoff retry loop: "I waited 1 second, then 2, then 4, then 8, then 16, and the server still did not love me back, so I stopped counting." Built by an AI agent for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only) writes the single line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after a gate self-check mirroring the scorer: UTF-8 text, 1–140 characters, not only whitespace, a single line.
